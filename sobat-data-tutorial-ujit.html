Cara Uji t di SPSS – Panduan Lengkap + Interpretasi Hasil

⏱ Estimasi baca: 8 menit 🔰 Tingkat: Pemula 🔄 Diperbarui: 2024 👁 1.243 views

Panduan lengkap cara melakukan uji t di SPSS — mulai dari Independent Sample T-Test hingga Paired Sample T-Test — beserta langkah-langkah input data, pengujian, dan cara membaca output SPSS secara mudah.

💡
Sebelum Mulai – Apa itu Uji t?

Uji t adalah uji statistik yang digunakan untuk membandingkan rata-rata dua kelompok data. Ada dua jenis utama: Independent Sample T-Test (dua kelompok berbeda/tidak berpasangan) dan Paired Sample T-Test (satu kelompok diukur dua kali, misalnya pre-test dan post-test).

Bagian 1: Uji t Independent Sample (Dua Kelompok Berbeda)

Uji t independent digunakan ketika kamu ingin membandingkan rata-rata dua kelompok yang berbeda/tidak berpasangan. Contoh: membandingkan rata-rata nilai ujian antara kelompok A (metode ceramah) dengan kelompok B (metode diskusi).

Syarat Penggunaan

  • Data berskala interval atau rasio (kuantitatif)
  • Kedua kelompok tidak berpasangan (independent)
  • Data berdistribusi normal (bisa dicek dengan uji Shapiro-Wilk atau Kolmogorov-Smirnov)
  • Varians kedua kelompok homogen (dicek via Levene's Test)
⚠️
Penting!

Sebelum uji t, lakukan uji normalitas terlebih dahulu. Jika data tidak normal, gunakan alternatif non-parametris yaitu Mann-Whitney U Test (untuk independent) atau Wilcoxon (untuk paired).

Langkah-Langkah di SPSS

1

Input Data di Variable View

Buka SPSS → klik Variable View. Buat dua variabel:
Variabel pertama: Hasil (nilai ujian, tipe Scale).
Variabel kedua: Kelompok (tipe Nominal) — isi dengan kode 1 = Kelompok A, 2 = Kelompok B.

2

Masukkan Data di Data View

Klik Data View. Masukkan data nilai dan kode kelompok sesuai masing-masing responden. Pastikan data sudah lengkap dan tidak ada yang kosong.

3

Akses Menu Uji t Independent

Klik menu: Analyze → Compare Means → Independent-Samples T Test...

4

Atur Variabel

Pindahkan variabel Hasil ke kotak Test Variable(s). Pindahkan variabel Kelompok ke kotak Grouping Variable. Klik Define Groups → isi Group 1: 1, Group 2: 2. Klik Continue.

5

Klik OK dan Lihat Output

Klik OK. SPSS akan menampilkan jendela output dengan beberapa tabel hasil analisis.

Membaca Output Uji t Independent

Ada dua tabel utama yang perlu diperhatikan: Group Statistics dan Independent Samples Test.

📋 Contoh Output: Group Statistics
KelompokNMeanStd. DeviationStd. Error Mean
Kelompok A (1)677,839,453,86
Kelompok B (2)587,246,723,01

Dari tabel di atas terlihat rata-rata Kelompok B (87,24) lebih tinggi dari Kelompok A (77,83). Namun apakah perbedaan ini signifikan secara statistik? Cek tabel berikutnya.

📋 Contoh Output: Independent Samples Test (fokus pada Sig. dan t)
Levene's FSig. LevenetdfSig. (2-tailed)
Equal variances assumed1,2340,289-2,419180,019
Equal variances not assumed——-2,48917,30,023
✅
Cara Baca Levene's Test dulu!

Lihat kolom Sig. Levene: jika > 0,05 → varians homogen → gunakan baris Equal variances assumed. Jika < 0,05 → tidak homogen → gunakan baris Equal variances not assumed. Pada contoh di atas: Sig. Levene = 0,289 > 0,05, jadi gunakan baris pertama.

Dasar Pengambilan Keputusan

Sig. (2-tailed) < 0,05

H₀ ditolak — Ada perbedaan signifikan antara rata-rata kedua kelompok

Sig. (2-tailed) > 0,05

H₀ diterima — Tidak ada perbedaan signifikan antara rata-rata kedua kelompok

Pada contoh di atas, Sig. (2-tailed) = 0,019 < 0,05, sehingga H₀ ditolak. Kesimpulan: terdapat perbedaan rata-rata nilai ujian yang signifikan antara Kelompok A dan Kelompok B.

Bagian 2: Uji t Paired Sample (Data Berpasangan)

Uji t paired digunakan ketika kamu mengukur satu kelompok yang sama sebanyak dua kali. Contoh: nilai siswa sebelum dan sesudah mendapat perlakuan (pre-test dan post-test), atau berat badan sebelum dan sesudah program diet.

Syarat Penggunaan

  • Data berskala interval atau rasio
  • Dua pengukuran berpasangan dari subjek yang sama
  • Selisih antar pasangan data berdistribusi normal

Langkah-Langkah di SPSS

1

Input Data di Variable View

Buka SPSS → Variable View. Buat dua variabel: Pretest dan Posttest. Keduanya bertipe Scale. Ubah kolom Decimals ke 0 jika data berupa angka bulat.

2

Isi Data di Data View

Masukkan nilai pre-test dan post-test tiap responden secara berpasangan per baris. Satu baris = satu responden.

3

Akses Menu Uji t Paired

Klik: Analyze → Compare Means → Paired-Samples T Test...

4

Atur Variabel Berpasangan

Pilih variabel Pretest dan Posttest di daftar kiri, lalu klik tanda panah untuk memasukkannya ke kotak Paired Variables sebagai satu pasang. Ubah confidence interval jika diperlukan (default 95% / α = 0,05).

5

Klik OK

Klik OK. Output akan muncul di jendela SPSS Output Viewer.

Membaca Output Uji t Paired

📋 Contoh Output: Paired Samples Statistics
MeanNStd. Deviation
Pretest54,621310,300
Posttest67,691310,727
📋 Contoh Output: Paired Samples Correlations
PairNCorrelationSig.
Pretest – Posttest130,9210,000

Nilai korelasi 0,921 menunjukkan hubungan yang sangat kuat antara pretest dan posttest. Sig. = 0,000 < 0,05, artinya korelasi tersebut signifikan.

📋 Contoh Output: Paired Samples Test (tabel utama keputusan)
PairMean Diff.tdfSig. (2-tailed)
Pretest – Posttest-13,077-8,451120,000
✅
Interpretasi Hasil

Sig. (2-tailed) = 0,000 < 0,05 → H₀ ditolak. Ada perbedaan yang signifikan antara nilai pretest dan posttest. Nilai Mean Difference = -13,077 (negatif karena Pretest - Posttest), artinya rata-rata posttest lebih tinggi 13 poin dibanding pretest.

Dasar Pengambilan Keputusan Paired T-Test

Sig. (2-tailed) < 0,05

H₀ ditolak — Ada perbedaan signifikan antara dua kondisi (sebelum dan sesudah)

Sig. (2-tailed) > 0,05

H₀ diterima — Tidak ada perbedaan signifikan antara dua kondisi

Ringkasan: Pilih Uji t yang Mana?

📌 Panduan Cepat Memilih Jenis Uji t
Kondisi DataJenis UjiMenu SPSS
2 kelompok berbeda, tidak berpasanganIndependent Sample T-TestAnalyze → Compare Means → Independent-Samples T Test
1 kelompok, diukur 2x (pre-post)Paired Sample T-TestAnalyze → Compare Means → Paired-Samples T Test
1 kelompok vs nilai referensiOne Sample T-TestAnalyze → Compare Means → One-Sample T Test
🚫
Jika Data Tidak Normal?

Gunakan uji non-parametris sebagai alternatif: Mann-Whitney U Test (pengganti independent t-test) atau Wilcoxon Signed Rank Test (pengganti paired t-test). Keduanya tersedia di menu Analyze → Nonparametric Tests.
